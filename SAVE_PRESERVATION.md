# Save preservation

Never instruct players to uninstall or clear data to bypass signature mismatch. Back up before updates. Prefer local, versioned portable exports with validated import, preview, confirmation and rollback. Exclude credentials, admission tokens and live multiplayer sessions from portable backups. Document what is and is not transferred.

Test actual old APK -> new APK without uninstall using noncritical seeded data. Check package/certificate, version, active game, records, earned rewards, preferences and any supported notes. Record exact APK hashes and outcome. Temporary matching test signers only validate migration logic.

If original key cannot be recovered, consider a separately packaged replacement ONLY with owner approval and tested export/restore. Leave old app installed; verify transferred progress before any removal. If transfer cannot be verified, keep the old app and explain limitations. Never promise recovery of unsupported data.
