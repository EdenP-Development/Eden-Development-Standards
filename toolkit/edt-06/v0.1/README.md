# EDT-06 v0.1 — Arcade objective selection

Original dependency-free ES module. Import decide(state, aggression=0.5) from decision.mjs. Supply normalized finite health, resources and threat (0..1), and boolean canRecover, canResupply, canEvade, visibleTarget, canReposition. Aggression is 0..1. The caller supplies a stable, observed snapshot of an active bot; do not call for dead/inactive actors. Zero health is accepted numerically for boundary testing, but lifecycle enforcement belongs to caller.

Eligible objectives are recover, resupply, evade, engage, reposition and patrol. Critical health <=0.2 forces available recovery, else evasion if threatened and available. Otherwise highest score wins, with ties resolved by insertion order. Returns version, chosen objective, reason and eligible score trace. No input mutation or random draws. Default weights and thresholds are provisional design choices, not balanced difficulty settings. Visibility flag must come from actual permitted perception; this module cannot verify line of sight or enforce fairness. No target IDs, last-seen memory, movement, physics, navigation, combat execution, persistence or multiplayer sync. Caller must check feasibility each tick and handle action completion, death and cooldowns.
