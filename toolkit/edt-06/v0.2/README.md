# EDT-06 v0.2 — Objective persistence and perception memory

Original dependency-free ES module, importing the unchanged sibling v0.1 decision engine. Call step(state,{tick,previous,observation,aggression,switchMargin,memoryTicks}). Tick is a nonnegative safe integer, strictly increasing when previous is supplied. Reset with previous=null. Supply previous output from the same active bot and simulation epoch. Defaults: aggression 0.5, switchMargin 8 points, memoryTicks 30. These are provisional tuning choices, not validated gameplay difficulty.

Retain the previous eligible objective if the best score advantage is at most switchMargin; critical-health override bypasses persistence. An ineligible previous objective is discarded. No guaranteed minimum dwell time. An explicit observation with finite x/y requires visibleTarget=true; absent observation retains earlier memory until tick-seenTick exceeds memoryTicks. Memory is copied, not mutated; a new observation replaces it. This is one position, not a target identity or multi-target tracker. Memory does not permit engagement, change scores or autonomously cause pursuit. The game must enforce real perception, actor lifecycle, observation identity, invalidation, coordinate bounds and navigation. Do not call for dead/inactive actors or use untrusted previous state as authorization. No wall-clock dependency, movement, combat execution, physics or networking.
