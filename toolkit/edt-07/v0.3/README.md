# EDT-07 v0.3 — Bounded learning

Original dependency-free JavaScript ES module. learn({previous,event,tick}) returns a new versioned skill snapshot. One completed learning event per agent per strictly increasing tick; caller must validate actual completion and avoid duplicate rewards across resets. Event fields: skill (ASCII ID 1–64), kind (eat/rest/safety/gather/work/explore/socialize), effort (integer 0–100), success (boolean). Each skill retains its kind and independent mastery/familiarity integers 0–1000; maximum 128 skills. No mutation of previous plain-data snapshot.

Gain = floor(effort * rate * (1000-current) / 100000). Mastery rate 20 on success, 4 on failure; familiarity rate 30 regardless of success. Integer rounding creates a plateau below 1000, potentially much earlier for low effort; no accumulated fractional credit. Zero effort grants zero points but can create a skill record. No decay, XP currency, profession locking, task preference changes, ML, world execution or automatic coupling to v0.1/v0.2. Caller owns agent identity, lifecycle, clock, persistence and legitimate outcomes. Parameters provisional; do not interpret scale as validated game balance.
