# EDT-07 v0.4 — Individual outcome memory and experience-informed utility

Original dependency-free ES module. Imports unchanged v0.1 decision engine; consumes v0.3 learning snapshots. remember({tick,previous,event}) stores at most 64 most recent events, each with task ID, kind, success boolean and tick. One event per strictly increasing tick per agent. IDs must be stable and not reused for unrelated tasks; matching also checks kind. Caller owns actor identity, lifecycle, world epoch and legitimate completion. Reset with null previous. No world mutation.

decideWithExperience(agent,tasks,{tick,memory,learning,memoryTicks=100}) validates snapshots, ignores memory older than memoryTicks (inclusive boundary), and invokes original selector. Only eligible gather/work/explore/socialize tasks get adjustments: mean success (+1)/failure (-1) of matching recent outcomes times 10, plus optional explicit task.skill mapping to same-kind learning skill, with bonus (6*mastery+4*familiarity)/1000. Total adjustment -10 to +20; no history gives zero bonus. Survival tasks and idle scores unchanged, original eligibility and lexicographic tie order preserved, survival priority compared before adjusted score. Trace exposes baseScore, outcomeBonus, skillBonus and final score. Unmapped or unknown skill has no bonus; mismatched known skill kind rejected. No exploration randomness, spatial memory, automatic decay of skill, profession locking, reservations or execution. One failure can cause a full -10 adjustment; no confidence weighting yet. All weights/limits provisional; no guarantee against repetitive selection. Expired records stay in bounded history until displaced. Snapshots are trusted internal plain data, not hostile save input or authorization.
