## Practical adoption
1. Product chats own exact release inventory and execution. Link existing records instead of duplicating them.
2. Central hub records only status and sanitized evidence; no private repository details, song account identifiers, contracts, receipts or credentials.
3. Prioritize near-release Sudoku and Sector Rebound, then Word Search, then Grid Hunt/Crossroads; Eden Comms rights review proceeds independently with its stricter security gates. Private and legacy products require separate private review before next distribution.
4. At release candidate, complete existing receipt; reuse unchanged verified evidence and resolve material unknowns. No automatic repository license, visibility, app, signing, or storefront changes.
5. Brand clearance and January 2027 optional entity decision remain separate.

Scope: read-only handoff/register inspection, not independent verification of cited CI runs, APK bytes, legal rights or dependency graphs. Word Search main README is historical, not current development authority. No product-side writes in this checkpoint.
