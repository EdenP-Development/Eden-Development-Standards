# GridMates: Sudoku — help page candidate

**PREPUBLICATION DRAFT — no active support service or confidential reporting contact established.**

## Getting the game
Use the [itch.io project](https://sir-spudacus.itch.io/gridmates-sudoku) for current Android availability and release instructions. Amazon and Google Play availability is not asserted here.

## Updating without losing progress
Check the release instructions and your installed version. If your version provides a progress export, save a copy outside the app and keep the original installation until the update and progress are verified. If Android refuses an update, stop: do not uninstall or clear data to bypass a signing mismatch. Preview packages may not update public packages, and backups have limitations.

## Nearby play
Use compatible devices on the same reachable trusted Wi-Fi network. Check that both are connected to the intended network and that the host room is open. Guest isolation on some networks can prevent devices from reaching each other. Use the room code if required. Do not expose a room to the internet. Local game traffic is not encrypted.

## Reporting a problem
Once an approved contact is available, provide the game version, distribution channel, device model and Android version, what you expected, what happened and steps to reproduce. Optional screenshots should be sanitized. Never send passwords, reconnection credentials, payment details, private messages or full save backups. Confidential privacy or security reports require a private channel, not public comments.

For purchases, use the applicable storefront's current support/refund process. No response-time or refund guarantee is made.
